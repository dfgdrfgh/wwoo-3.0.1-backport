# Temporary cloud measurement add-on

Use WWOO .16 (or .15 for comparison), Cirrus 1.4.1 and Fabric API installed. Replace the previous diagnostic JAR with this version (0.3); do not keep both. Add `wwoo-cloud-diagnostics-fabric-1.21.1.jar` to the same `mods` folder, then restart Minecraft. This is a separate client-only diagnostic; remove it after testing.

Aim the centre of the view at clouds/sky, as in the supplied clip. Use `/wwoocloud capture` or press **F8** to start a local capture, walk back and forth across the biome boundary for about 20–30 seconds, then use the same command/key again to stop. The key is now listed under **Options → Controls → Key Binds → WWOO Cloud Diagnostics → Start/stop cloud capture** and can be reassigned. `/wwoocloud status` confirms the add-on is loaded and reports recording state, sampled frames, CSV rows and cloud-covered points. The key uses Minecraft's queued press events, so a short tap between client ticks is retained. Recording also stops automatically after 60 seconds or when leaving the world. A small HUD shows each layer's style, input alpha and measured GPU fragment alpha. `no cloud at sampled points` means the sampled patch has no cloud fragments, not that cloud opacity became zero.

The local chat message identifies the CSV in the instance's `logs` folder: `wwoo-cloud-diagnostics-YYYYMMDD-HHMMSS-SSS.csv`. Send that CSV for analysis. Ideally repeat once with all Cirrus layers set to **Fast**, then once with the same settings set to **Fancy**. Keep the layer opacity sliders, time and weather settings the same. Separate captures make two separate CSVs; styles are recorded in each row. A matching clip is helpful.

Every half second, the add-on reads a small central patch before and after each visible cloud-layer draw and replays that same mesh/shader into a separate floating-point buffer to read the fragment RGBA before sky blending. The screen draw remains unchanged. Normal OpenGL state is restored after capture. The diagnostic adds some temporary render/readback work on sampled frames. Aim at sky to avoid terrain occlusion; the offscreen buffer resolves the layer's own geometry, not the world's terrain depth.

The CSV includes camera/biome information, spatial cloud tint, native sky RGB, native layer input opacity, Cirrus time/sun/weather/lightning uniforms, blend/depth state, and per-point fragment RGBA plus observed scene RGB. Nothing is transmitted by the add-on. The original WWOO biome transition, cloud shader and cloud configuration are not modified.
